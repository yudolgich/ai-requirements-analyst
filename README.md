# AI Requirements Analyst

Учебный агент для анализа требований к информационным системам с веб-интерфейсом Streamlit и CLI. Использует четыре последовательных вызова Gemini, LangGraph, локальную историю SQLite, RAG на Chroma и файловый MCP-сервер.

## Установка и запуск

Требуется Python 3.14 и Node.js с `npx` для файлового MCP-сервера.

```bash
python -m pip install -r requirements.txt
```

Сначала проверьте модели, доступные именно вашему API-ключу:

```bash
python check_gemini.py --list-only
```

В корне проекта создайте или дополните `.env` (существующий файл не перезаписывайте). Укажите `GEMINI_MODEL` из выведенного каталога. Если переменная не задана, используется `gemini-3.8-flash`, только когда каталог подтверждает её доступность; иначе приложение попросит явно выбрать модель:

```dotenv
GEMINI_API_KEY=ваш_ключ
# GEMINI_MODEL=имя_модели_из_каталога
```

Для проверки одного минимального запроса к выбранной доступной модели выполните `python check_gemini.py --timeout 12`. Скрипт выводит список моделей, затем отправляет ровно один запрос только к выбранной модели; повторы и переключение отключены. SDK Gemini требует тайм-аут не менее 10 секунд. Для одного лишь списка используйте `--list-only`. Автоматические вызовы приложения при 503/504, 429 и сетевых сбоях ограничены тремя попытками на одной модели с экспоненциальной задержкой и случайным разбросом; также учитывается `Retry-After`. Общий бюджет вызова по умолчанию 60 секунд, таймаут попытки — 18 секунд. Настройки: `GEMINI_RETRY_BUDGET_SECONDS` и `GEMINI_MAX_ATTEMPTS` (по умолчанию 3). Ошибки авторизации и конфигурации автоматически не повторяются.

```bash
python app.py
```

В меню можно создать сессию, продолжить существующую и просмотреть историю. Пустое требование не запускает анализ. История доступна и без API-ключа; для вызова агентов ключ обязателен.

## Веб-интерфейс

После установки зависимостей и настройки `.env` запустите интерфейс:

```bash
streamlit run web_app.py
```

Требование отправляется на анализ только после нажатия кнопки. Ход выполнения показывает фактические этапы графа; результаты четырёх агентов, статусы RAG/MCP и источники сохраняются в ту же SQLite-базу, что использует CLI. Предыдущие результаты можно открыть в боковой панели без повторного вызова Gemini. После временного сбоя кнопка «Повторить анализ» возобновляет текущую сессию из сохранённого checkpoint, не вызывая уже завершённые узлы повторно. Без `GEMINI_API_KEY` доступна история, но новый анализ не запускается.

## Архитектура

- `graph.py` задает последовательность узлов LangGraph: MCP, RAG, аналитик, специалист по уточнению, формализатор и контролер качества. Четыре последних узла независимо вызывают модель и передают результаты через общее состояние.
- `agents.py` содержит роли и инструкции агентов. Неизвестные бизнес-правила не должны подаваться как факты.
- `memory.py` хранит сессии и результаты в `data/analysis.sqlite3`. LangGraph `SqliteSaver` хранит checkpoints в том же файле; `thread_id` соответствует сессии.
- `rag.py` индексирует `.md`, `.txt` и `.rst` из `knowledge_base/`, делит документы на фрагменты и ищет их через постоянный Chroma в `data/chroma/`. Используется встроенная локальная модель Chroma `all-MiniLM-L6-v2`; первое индексирование может скачать модель. Если документов нет или поиск не дал совпадений, анализ продолжается с явным сообщением об этом.
- `mcp_tools.py` подключается через `langchain-mcp-adapters` к настоящему файловому MCP-серверу. По умолчанию сервер запускается командой `npx -y @modelcontextprotocol/server-filesystem <папка knowledge_base>`; он получает доступ только к папке базы знаний. В рабочем графе вызываются `list_directory` и `read_file`, а прочитанные материалы передаются агентам.

## База знаний и MCP

Документы в `knowledge_base/` — демонстрационные примеры, не официальные стандарты. Добавляйте свои `.md`, `.txt` или `.rst`; переиндексация выполняется при старте или отдельно:

```bash
python app.py --index-knowledge
python app.py --check-mcp
```

Для другого файлового MCP-сервера задайте `MCP_FILESYSTEM_COMMAND` и `MCP_FILESYSTEM_ARGS` в `.env`; аргументы должны быть JSON-массивом строк. Сервер должен предоставлять инструменты `list_directory` и `read_file`. По умолчанию используется официальный пакет `@modelcontextprotocol/server-filesystem`; `npx` скачает его при первом запуске, поэтому нужен доступ к npm registry. Ошибки MCP не блокируют анализ: соответствующий статус показывается в результате.

## Тесты

```bash
python -m pytest -q
```

Автоматические тесты используют подставную модель, чтобы не отправлять платные запросы. Диагностика Gemini требует действующий ключ и использует только модель, подтверждённую каталогом текущего ключа.
